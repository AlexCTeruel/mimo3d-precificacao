# 🎁 Mimo3D — Calculadora de Precificação

Calculadora de preço com taxas Shopee (vendedor CPF), desconto PIX, sugestão de preço e análise de margem.

## Como rodar localmente

```bash
npm install
npm start
```

Abre em http://localhost:3000

## Como fazer o build

```bash
npm run build
```

## Deploy no Vercel

1. Sobe esse repositório no GitHub
2. Acessa vercel.com e importa o repositório
3. Vercel detecta React automaticamente e faz o deploy
